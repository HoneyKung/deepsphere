# เรขาคณิตวงจอหกเหลี่ยม

## หน่วยพิกัดที่ใช้ในตัวเรนเดอร์

พิกัดวงจรอบวงของโหมด ring และ sphere ใช้ `ringLengthMm = 2πR` แยกจาก `strip_map.length_mm` ของภาพคลี่ cube โดยค่าปัจจุบันคือ R = 25.461 มม., รอบวง 159.977 มม. ส่วน strip map เดิมยาว 212.132 มม. การใช้ความยาวคนละชุดทำให้การเลื่อนสัตว์และพื้นแปลงจากพิกัดเดิมด้วยสัดส่วน `ringLengthMm / stripLengthMm` เพื่อคงมุมและความเร็วเชิงมุมเดิม

แนวตั้งของจอวงใช้ระยะส่วนโค้งเดียวกับแนวนอน: `ringPanelArcMm = R × ringOpeningAngle` ซึ่งปัจจุบันเท่ากับ 21.935 มม. ต่อจอ ส่วน sphere ใช้เส้นรอบวงเดียวกันในแนวนอนและครึ่งเส้นรอบวง `πR` จากขั้วถึงขั้วในแนวตั้ง จึงได้สเกลมิลลิเมตรต่อพิกเซลเท่ากันที่เส้นศูนย์สูตร ระนาบวงแหวนและจุดเล็งอยู่ที่ y = 0

ระยะขอบในภาพจริงเกิดจากมุมที่เหลือระหว่างจอข้างเคียง: `bezelArcMm = R × (2π/n - ringOpeningAngle)` ค่าปัจจุบันของหกจอเท่ากับ 4.728 มม. ตัวเลขนี้ต่างจาก `bezel_mm = 6` ซึ่งเป็นค่าระยะก้าวที่ใช้กำหนดรัศมีอ้างอิง การทดสอบตรวจช่องว่างจากมุมขอบจริงของทุกจอและยืนยันว่าคงที่รอบวง

เว็บเก็บทะเลและสิ่งมีชีวิตไว้ในแผนที่ทรงกระบอกชุดเดียวกับทรงกลม ส่วนตัวเครื่องวงจอใช้หน้าจอแบน n ใบที่ตั้งตรงหันออกจากแกนกลาง แต่ละใบเป็นหน้าต่างมองเข้าไปยังตำแหน่งละติจูด/อะซิมัทเดียวกันในแผนที่นั้น

## สูตรแมป

ให้ `n` เป็นจำนวนจอ, `w` เป็นความกว้างภาพจริงต่อจอ, `b` เป็นระยะขอบที่มุม, `p = w + b` เป็นระยะก้าวรอบวง และ `R = p / (2 tan(π/n))` เป็นรัศมีอ้างอิงของวง สำหรับตำแหน่งพิกเซล u ในช่วง 0..1 ของจอ i:

```text
centerAngle(i) = 2π i/n + reticleAzimuth
angle(i,u) = centerAngle(i) + atan((u - 0.5) w/R)
Lring = 2πR
openingAngle = 2 atan(w/(2R))
panelArc = R × openingAngle
stripX = wrap(angle / 2π * Lring, Lring)
stripY = (0.5 - v) panelArc
```

การใช้ `atan` แปลงระยะบนจอแบนเป็นมุมจริงทำให้แนวภาพอ้างอิงกับทรงกระบอก ไม่ใช่สัดส่วนเชิงเส้นตามความกว้างจอ `Lring` เป็นเส้นรอบวงจริงของ ring/sphere และแยกจากความยาว strip ของ cube ที่ 212.132 มม. ส่วนแนวตั้งใช้ระยะส่วนโค้งเท่ากับแนวนอนเพื่อให้มิลลิเมตรต่อพิกเซลเท่ากัน ทะเลจึงต่อเนื่องเมื่อวนผ่าน 0/360 องศาและเมื่อหมุนครบหนึ่งรอบ

เป้าเล็งเลือกจอที่มีแนวกลางใกล้มุมเป้าหมายที่สุด คำนวณตำแหน่ง u ด้วยสมการผกผัน `u = 0.5 + tan(deltaAngle) R/w` แล้วอ่านดัชนีสัตว์จากพิกเซลใน canvas ของจอนั้นจริง หาก u อยู่นอกช่วง 0..1 เป้าจะอยู่ในช่องขอบและไม่เลือกสัตว์

## ค่ากำหนด

หัวข้อ `ring` ใน `config/twin.json` กำหนดจำนวนจอ (6), ขนาดภาพจริง (23.4 มม.), ระยะขอบ (6 มม.), ความละเอียด (240 พิกเซล), ลำดับติดตั้ง, มุมเป้า และระยะเลื่อนความลึก (480 มм., ต้องเท่ากับ `strip_map.depth_travel_mm`) ค่าขนาด/ลำดับยังเป็นค่ารอวัดและยืนยันจากเจ้าของ

## ผังด้านบน

```text
                        จอ 6: pz
                 จอ 5: ny     จอ 1: px
                     \           /
                 จอ 4: py  ●  จอ 2: nx
                       \       /
                        จอ 3: nz

       ● = แกนตั้ง/ศูนย์กลาง     เป้าเล็ง = อะซิมัท 0°
       ทิศลำดับใน config: px → nx → py → ny → pz → nz → กลับ px
```

มุมจอในโมเดลเป็นระยะเท่ากันรอบแกน และลำดับรหัสเป็นตัวระบุช่องทางตั้งค่า ลำดับสาย/ตำแหน่ง CS จริงต้องยืนยันก่อนทำเฟิร์มแวร์

## งานเฟิร์มแวร์ใบถัดไป

- ใช้ค่าจาก `ring` ชุดเดียวกัน และยืนยัน mapping รหัสจอ px,nx,py,ny,pz,nz กับ CS 8,3,4,5,6,7
- แปลงพิกเซลจอจริงเป็นมุมด้วยสมการ `atan` เดียวกัน แล้ว wrap ตามความยาวแถบเดียวกับทรงกลม
- รักษาการเลื่อนความลึก 480 มม., ตำแหน่งช่องลง, mask สัตว์ และ yaw ให้ตรงกับเว็บ
- สร้างภาพ/เป้าเล็งจากพิกเซลบนจอที่แสดงจริง และตรวจภาพต่อเนื่องที่ขอบจอกับการหมุน 360°
- รอเจ้าของวัดขนาดพื้นที่ภาพ, ระยะขอบที่มุม และยืนยันลำดับติดตั้งก่อนปรับค่าเริ่มต้น

## รอบแก้ 2 — ความกว้างภาพและตำแหน่งแนวนอน

ระยะสูงของภาพแต่ละจอใช้ `ringPanelWidth` (ความกว้างจริงของจอ) เพื่อให้สเกลมิลลิเมตรต่อพิกเซลเท่ากันทั้งแนวนอนและแนวตั้ง `ringPanelArcMm` ยังคงเป็นระยะตามส่วนโค้งสำหรับรายงานมุมเท่านั้น การวาดภาพสัตว์ใช้ `ringCanvasX` ซึ่งผกผันสูตร `atan` ของพิกัดพิกเซลบนจอ จึงวางตำแหน่งตรงกับภาพทะเลและการตรวจชน

ช่องผ่านในโหมด ring/sphere ใช้ `ringLengthMm` ร่วมกันทั้งตอนวาดพื้นและตรวจการชน ส่วน cube ยังคงใช้ `stripLengthMm` การวาดความสว่างของช่องและสถานะผ่านเรียกสูตรเปิดช่องร่วมกัน โดยมีการทดสอบความสอดคล้องตลอด yaw 0–359.99 องศา
