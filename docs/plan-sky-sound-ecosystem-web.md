## 2. เสียง: จะเล่นไฟล์เดิมยังไง

**นาฬิกาจังหวะกลาง 1 ตัว** เดินตั้งแต่เริ่มดำ ตามจังหวะเพลงเดิม (6/8, 72): เขบ็ต 0.278 วิ · ห้อง 1.67 วิ · ประโยค 8 ห้อง 13.33 วิ ทุกอย่างเกาะนาฬิกานี้ แม้ตอนเพลงเงียบ

### เพลง (ไฟล์เดิม 4 ชั้น: pad / motion / lead / sparkle)
- **ไม่วน:** เล่นไปข้างหน้ารอบเดียว (`loop = false`) รอบถัดไปเล่น **ต่อจากประโยคถัดไป** ไม่ย้อนไปต้นเพลง · จบไฟล์ = จบเพลง แล้วพักยาว
- **ตามผู้เล่น:** หมุนหรือดำต่อเนื่อง ~1.2 วิ → pad เข้า (ตรงเส้นห้อง) → อีก 1 ห้อง motion → อีก 2 ห้อง lead · sparkle มาเฉพาะตอนสแกนเจอ/เก็บได้
- **หยุดแล้วค่อย ๆ เบาลง แม้ไม่จบเพลง:** หยุดขยับ 4 วิ → lead จาง 2.5 วิ, motion 3.5 วิ, pad 7 วิ → เงียบ เหลือทะเล · ถ้าขยับอีกทีระหว่างกำลังจาง เพลงกลับขึ้นมาต่อเลย
- **ไม่ยาวจนรำคาญ:** หนึ่งรอบไม่เกิน 2–3 ประโยค (27–40 วิ) แล้วจางเองที่จบประโยค พัก 16–30 วิ (หยุดเองพัก 10–18 วิ · จบเพลงพัก 24–40 วิ)
- เปลี่ยนชั้นความลึก: เพลงเก่าจาง 3 วิ → เสียงเชื่อมเดิม → เพลงชั้นใหม่เข้าเมื่อยังขยับ
- เปิดเรื่อง: เพลง `invite` เล่น 2 ประโยคแล้วจาง · นิ่งนาน 55–85 วิ จะมี 1 ประโยคเบา ๆ ลอยมาแล้วหายไป
- `discovery` และ `home` เล่นครั้งเดียวตามเหตุการณ์เหมือนเดิม

### ทะเลยาว เสียงฮัม เสียงเครื่องดำ (ไฟล์เดิม)
- **ทะเล `ambient_*`:** ไม่ใช้ปุ่มวน เล่นเป็น "เที่ยว" เริ่มจากจุดสุ่มในไฟล์ ก่อนหมดเที่ยวให้เที่ยวใหม่จากอีกจุดซ้อนเข้ามาแบบจางทับ 8 วิ ความเร็วต่างกันเล็กน้อย (±3%) จึงไม่มีรอยต่อจุดเดิมให้จับได้ · ความดังหายใจช้า ๆ ทุก 4 ห้อง
- **ฮัมห้องโดยสาร `sub_roomtone`:** ไม่เปิดค้าง มาเป็นระลอก 14–22 วิ (เข้า 5 ออก 7) แล้วหาย 30–60 วิ
- **เครื่องดำ `descend_thrust`:** ดังเฉพาะตอนกดดำ ปล่อยแล้วจาง 1 วิ · สลับ 2 ไฟล์แบบจางทับ ไม่วนไฟล์ 5 วิ
- **วาฬ `whale_distant` (62 วิ):** เล่นทีละช่วง 18–26 วิ จากจุดสุ่ม มีเฟดเข้าออก ไม่เปิดทั้งไฟล์

### เสียงครั้งเดียว (ไฟล์เดิมทั้งหมด)
- ฟอง ทำนองสัตว์ สแกนเจอ เก็บได้ เข้าเขต เสียงตัวเรือ → เลื่อนให้ลงเขบ็ตถัดไป (ช้าสุด 0.28 วิ) จึงฟังเป็นจังหวะเดียวกับเพลง
- ฟองตอนดำ: ห่างกัน 3/5/6/8/9/12 เขบ็ตแบบสุ่ม (0.8–3.3 วิ) ไม่เท่ากันทุกครั้ง
- เสียงกดปุ่ม/คลิกหมุน/เสียงผิดพลาด ดังทันที ไม่หน่วง

### มือเป็นเครื่องดนตรี (เพิ่ม ไม่แทนอะไร · สังเคราะห์สดในเบราว์เซอร์ ไม่มีไฟล์ใหม่)
- หมุนทุก 30° = โน้ตเบา ๆ 1 ตัวเดินตามทำนองธีม (หมุนกลับ = ย้อนทำนอง) · ดำลงทุก ~120 ม. = โน้ตไล่ลง ขึ้น = ไล่ขึ้น
- เบากว่าเพลง ไม่เกิน 1 โน้ตต่อครึ่งเขบ็ต · ปิดได้ด้วยปุ่ม `N`

### กติกาเดิมที่คงไว้
เสียงพากย์ (นโยบายพูดซ้ำ), เสียงสัตว์ (พัก 20 วิ/ตัว), เสียงบรรยากาศห่างกัน ≥ 10 วิ, การหรี่เสียงอื่นตอนพากย์

## 3. ภาพ: ระบบนิเวศบนจอลูกบาศก์

วาดทับบนจอ 6 ใบและขอบไร้รอยต่อ ด้วยการแปลงพิกัดทะเล → จอแบบตรง ๆ (ไม่คิดทุกพิกเซล จึงไม่หน่วง) ทุกอย่างเลื่อนขึ้นตอนดำลง ทิศเดียวกับปลา

| ชั้น | บรรยากาศ | สิ่งมีชีวิตประดับ (สแกนไม่ได้ ตัวเล็กและจางกว่าตัวจริง) |
|---|---|---|
| ตื้น 0–760 ม. | ลำแสงแดดเฉียงแกว่งช้า ๆ, ฟองอากาศลอยขึ้น | ฝูงปลาจิ๋ว |
| กลาง 760–1,976 ม. | หิมะทะเล (ตะกอนลอยลง), แสงจาง | แมงกะพรุนจิ๋วลอยเป็นกลุ่ม, เงาวาฬผ่านไกล ๆ พร้อมเสียงวาฬ |
| ลึก 1,976–3,040 ม. | **แพลงก์ตอนเรืองแสง** กะพริบ สว่างวาบเมื่อหมุน/ขยับ (เหมือนถูกกวน) และเต้นเบา ๆ ตามจังหวะเพลง | สายจุดเรืองแสงเคลื่อนช้า ๆ |
| ก้นทะเล ~2,700 ม.+ | พื้นหินโผล่จากด้านล่าง, ปล่องน้ำร้อนมีควันเรืองแสง, หนอนท่อ | — |

ฟองเพิ่มตอนกำลังดำ (ตรงกับเสียงฟอง) · งบ ≤ 5 มิลลิวินาที/เฟรม วัดก่อน-หลัง · ตัวที่สแกนได้ 8 ตัวเดิมไม่เปลี่ยน

## 4. เว็บสำหรับเพื่อน

- โหมดผู้เล่นเป็นค่าเริ่มต้น: ซ่อนปุ่มวิศวกรรม แถบ DIGITAL TWIN ป้ายชื่อหน้า เส้นกริด แถบจอแบน · `?dev=1` เปิดกลับครบ
- ปุ่มบนจอ (มือถือใช้ได้): ดำลง/ขึ้นแบบกดค้าง, สแกน, เก็บ, วิเคราะห์, ปิดเสียง · ลากนิ้ว/เมาส์เพื่อหมุน · หน้าแรกบอกวิธีเล่นสั้น ๆ
- เสียงสำหรับเว็บ: ทำ **สำเนาบีบอัด MP3 ของไฟล์เดิม** ไว้ที่ `assets/audio/web/` (ต้นฉบับ WAV/OGG ไม่แตะ) เพราะต้นฉบับรวม ~150 MB โหลดบนมือถือไม่ไหว และ iPhone รุ่นเก่าเปิด OGG ไม่ได้ · ตัวเล่นลองสำเนาเว็บก่อน ไม่มีก็ใช้ต้นฉบับ
- `index.html` ที่รากโปรเจกต์ พาเข้า `twin/`

## 5. git และลิงก์

- `git init` ที่ `prototype-v1/` · `.gitignore` กันไฟล์ทดลอง (`assets/audio/temp`, สำรอง `twin_backup_*`, `tmp`, `.pio`) · commit · push ขึ้น GitHub · เปิด GitHub Pages → ลิงก์ `https://<ชื่อ>.github.io/<repo>/`
- เครื่องนี้ไม่มี `gh` การสร้าง repo/ล็อกอินอาจต้องให้ผู้ใช้กดยืนยัน 1 ครั้ง
- ต้องบอกตรง ๆ ตอนเผยแพร่: เสียงของเพื่อน 13 ไฟล์ไม่ทราบที่มา และเสียงพากย์มาจาก edge-tts — ขึ้นเว็บสาธารณะได้ตามที่สั่ง แต่จะเขียนที่มาเท่าที่รู้ใน `CREDITS.md`

## 7. ลำดับทำและวิธีตรวจ

1. เสียงใน `twin.js` → ตรวจในเบราว์เซอร์ด้วยตัวเลข: ไม่มีแหล่งเสียงไหน `loop = true`, เพลงเข้าเมื่อขยับ, หยุดแล้วระดับเพลงลดลงจนเงียบภายใน ~11 วิ, มีช่วงพักจริง, เวลาเริ่มเสียงลงเส้นจังหวะ, ไม่มี error
2. ภาพระบบนิเวศ → ดูภาพจริงที่ 4 ความลึก + วัดเวลาต่อเฟรม
3. โหมดผู้เล่น + ปุ่มบนจอ → ลองจอ 390×844 และจอคอม
4. สำเนาเสียงเว็บ → เปิดผ่านเซิร์ฟเวอร์ เล่นครบรอบ (เริ่ม → หมุน → ดำ → สแกน → เก็บ → ลึกสุด → ขึ้น)
5. git + Pages → เปิดลิงก์จริงตรวจซ้ำ

**ข้อจำกัด:** ผมฟังเสียงเองไม่ได้ ตรวจได้ด้วยตัวเลข (จังหวะ ระดับ การเข้า-ออก) ความไพเราะต้องให้ผู้ใช้ฟังตัดสิน · เทสเดิมของลูน่าบางตัวจะไม่ผ่านเพราะค่าเริ่มต้นเปลี่ยนไปตั้งแต่รอบก่อน จะรายงานตามจริง
