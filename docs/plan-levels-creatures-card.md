# แผนงาน: ปลาสวยขึ้น · การ์ดสปีชีส์ตอนเก็บ · สำรวจลงทีละชั้น (9 ต.ค. 2026)

ผู้ทำ: Claude เขียนโค้ดเอง แก้ในเว็บทวินเดิม `prototype-v1/twin/` · ไม่แตะไฟล์เสียง ไม่เปลี่ยนระบบเสียงที่เพิ่งทำ

## 1. ปลาสวยขึ้น
- ตอนนี้ปลาเป็นบล็อก 8×8 สีเดียว → วาดใหม่เป็นภาพเวกเตอร์ มีไล่สี ครีบ ตา และขยับได้ (หางสะบัด ครีบโบก ร่มแมงกะพรุนหุบ-กาง)
- 8 ตัว: ฝูงปลาเงินทอง · ปลาส้มลายขาว · ม้าน้ำตัวตั้ง · กระเบนราหูโบกปีก · ปลาตะเกียงมีจุดเรืองแสงวิ่งตามท้อง · แมงกะพรุนโปร่งแสง · ปลาตกเบ็ดมีไฟล่อ · หมึกมีจุดสีกะพริบ
- ตำแหน่ง ขนาด ทิศว่าย และการตรวจ "อยู่ในเป้า" ใช้ของเดิมทั้งหมด (สแกน/เก็บทำงานเหมือนเดิม) เปลี่ยนแค่ภาพที่วาด
- กรอบช่วยมอง (ตอนสแกน / ปุ่ม H) เปลี่ยนเป็นวงเล็บมุมสีเขียวรอบตัวปลา
- `?sprites=blocks` กลับไปดูบล็อกแบบเฟิร์มแวร์ได้

## 2. การ์ดสปีชีส์ตอนเก็บ
- กด Collect สำเร็จ → การ์ดเด้งขึ้น: ภาพสัตว์ (ขยับได้) · ชื่อไทย + อังกฤษ · ชั้นและความลึกที่พบ · คำอธิบาย 1 บรรทัด · เกร็ดความรู้ 1 ข้อ · "ตัวอย่างที่ n จาก 8"
- กด Analyze → รายการทุกตัวที่เก็บแล้ว มีภาพย่อ ชื่อ ความลึก ตัวที่ยังไม่เจอแสดงเป็น "?"
- ข้อความสปีชีส์เขียนใหม่ (ไม่ได้คัดจากเดโมเก่า) เป็นข้อเท็จจริงทั่วไปของสัตว์กลุ่มนั้น

## 3. สำรวจลงทีละชั้น
ทะเลแบ่งเป็น 3 ชั้น คั่นด้วย "พื้น" ที่มีช่องทางลงช่องเดียว ต้องหมุนกล่องหาช่องก่อนจึงลงต่อได้

| ชั้น | ความลึก | ฉาก | พื้นท้ายชั้น |
|---|---|---|---|
| 1 แนวปะการัง | 0–760 ม. | แสงแดด ฟอง ฝูงปลา | พื้นทราย ปะการังกิ่ง พัดทะเล ดอกไม้ทะเล ปลาดาว · ช่องลง = โพรงในแนวปะการัง มีฟองลอยขึ้น |
| 2 ซากเรือ | 760–1,976 ม. | หิมะทะเล แมงกะพรุน | ลานหินมีซากเรือเอียง เสากระโดงหัก ช่องหน้าต่างมีแสงริบหรี่ · ช่องลง = รอยแยกข้างซากเรือ มีแสงเรือง |
| 3 ภูเขาไฟใต้น้ำ | 1,976–3,040 ม. | แพลงก์ตอนเรืองแสง | พื้นหินบะซอลต์ รอยแตกลาวาเรืองแสง ปล่องน้ำร้อน หนอนท่อ (ก้นสุด ไม่มีช่องลง) |

กติกา
- เป้าเล็ง (ด้านหน้ากล่อง) คือตำแหน่งยาน: ลงผ่านพื้นได้เมื่อเป้าอยู่ตรงช่องเท่านั้น ขากลับขึ้นก็ต้องผ่านช่องเดิม
- ชนพื้น: เสียงกระทบเบา ๆ + ข้อความ "หมุนหาทางลง" · ชนซ้ำจะบอกทิศ ◀ / ▶ ว่าช่องอยู่ทางไหน
- เป้าตรงช่อง: เป้าเปลี่ยนเป็นสีทอง มีลูกศรชี้ลง + ข้อความ "เจอช่องแล้ว กดดำลง"
- ผ่านช่อง: พื้นเลื่อนผ่านขึ้นไปเป็นเพดานถ้ำ เสียงเข้าเขต + เพลงชั้นใหม่ (ของเดิม)
- ปุ่ม R กลับผิวน้ำได้เสมอ · `?gates=0` ปิดระบบชั้น (สำหรับตรวจงาน)
- ป้ายชั้นมุมซ้ายบนเปลี่ยนเป็น "ชั้น 1 · แนวปะการัง" ฯลฯ

ตำแหน่งสัตว์เดิมเข้ากับชั้นอยู่แล้ว: ชั้น 1 = ฝูงปลา ปลาส้ม ม้าน้ำ · ชั้น 2 = กระเบน ปลาตะเกียง · ชั้น 3 = แมงกะพรุน ปลาตกเบ็ด หมึก

## 4. ไฟล์ที่แตะ
| ไฟล์ | ทำอะไร |
|---|---|
| `twin/renderer.js` | ภาพสัตว์เวกเตอร์, พื้นแต่ละชั้น, ลูกศรที่เป้า |
| `twin/twin.js` | กติกาชั้น (ชน/ผ่านช่อง/คำใบ้), การ์ดสปีชีส์, รายการ Analyze |
| `twin/index.html`, `twin/deepcore.css` | โครงการ์ด |
| `config/twin.json` | ตำแหน่งช่องทางลง (`gates`) |

## 5. วิธีตรวจ
1. ดูภาพจริงของสัตว์ทั้ง 8 ตัวและพื้นทั้ง 3 ชั้น
2. กติกาชั้นด้วยตัวเลข: ดำลงตอนเป้าไม่ตรงช่อง → ความลึกหยุดที่พื้น · หมุนให้ตรง → ผ่าน · ขากลับเหมือนกัน
3. สแกน → เก็บ → การ์ดขึ้นพร้อมรายละเอียด · Analyze แสดงรายการ
4. วัดเวลาต่อเฟรม ไม่ให้ช้ากว่าเดิมจนรู้สึกได้ · ไม่มี error
