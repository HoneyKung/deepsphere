## 1. เป้าเล็ง: จุดบนผิวที่ความสูงคงที่ ไม่ใช่รังสีจากศูนย์กลาง

ข้อเท็จจริงเรขาคณิต (หน้า 50 มม.): จุดกลางหน้าบน px/py/pz อยู่สูง **h = 25/√3 ≈ 14.434 มม.** และมุมข้างทั้งสองของหน้าบน (มุมที่ไม่ใช่ยอดบนและยอดล่างของหน้า) ก็อยู่สูงเท่ากันพอดี
→ เส้น `h = 14.434` บนหน้าบนแต่ละหน้าคือ **เส้นทแยงแนวนอนที่ผ่านกลางจอ** จากมุมข้างหนึ่งไปอีกมุมข้าง และต่อกันเป็นสามเหลี่ยมรอบตัว

กำหนดใหม่:
- เป้าเล็ง = **จุดบนผิวลูกบาศก์ที่ azimuth ด้านหน้าในโลก (ทิศเดิมจาก `aim_world`) และความสูง `aim_height_mm = 25/√3`**
- ลบ `aim_elevation_deg` และรังสีเงยออก · เก็บ `aim_height_mm` ใน `config/twin.json`
- ผล: หมุนลูกบาศก์ → เป้าวิ่ง**เป็นเส้นตรง**ตามแนวทแยงของจอบน ผ่าน**กลางจอพอดี** ข้ามไปหน้าถัดไปที่มุมข้าง (ซ่อนใต้กรอบ) ลำดับ px → py → pz
- บนจอ 240×240 เป้าจะวิ่งตาม**เส้นทแยงของจอ** (เพราะจอเป็นข้าวหลามตัดเมื่อมองจากด้านข้าง) — ถูกต้อง
- ค่าตรวจทานของ Claude: หมุนครบรอบ เป้าอยู่บนจอราว **76.8%** (ระยะจากกลางหน้า s = r₀·tanθ, r₀ = √(25² − 14.434²) ≈ 20.41 มม., ขอบช่องจอตามแนวทแยง 15√2 ≈ 21.21 มม. → θ ≤ 46.1° จาก 60°) — **คำนวณซ้ำเองด้วยโค้ดจริง**
- hit test ใช้ `(φ, h)` ของจุดนี้ ฟังก์ชันเดียวกับการวาด

## 2. ปลา: รูปร่างเป็นมิลลิเมตรจริงบนกระจก ไม่ยืด

- ขนาดปลาใน `config/twin.json` เป็น **`w_mm`, `h_mm`** (แทน `w`, `h` ที่เป็นหน่วย u)
- ตัดสินว่าพิกเซลอยู่ในปลาไหม ด้วย **ระยะจริงบนผิว** จากจุดกลางปลา:
  - แนวนอน `Δs` = ระยะทางตามเส้นรอบรูปหน้าตัดแนวนอน (เส้นตรงบนแต่ละหน้า ต่อข้ามขอบและกรอบ) ระหว่าง azimuth ของพิกเซลกับของปลา
  - แนวตั้ง `Δv = Δh · √(3/2)` (หน้าเอียง 54.74° จากแนวนอน ความสูงเปลี่ยน 1 มม. = เดินบนหน้า 1.2247 มม.)
  - หรือวิธีคลี่หน้าแบบอื่นที่ได้ผลเทียบเท่า ถ้าอธิบายในรายงาน
- ความเร็ว: คงแบบ closed-form (ห้ามสะสมทีละเฟรม — บอร์ดกับทวินต้องได้ตำแหน่งเดียวกันจากเวลาเดียวกัน) โดยคิดอัตรามุมจาก `speed_mm_s` ที่**ความสูงอ้างอิง `aim_height_mm`** และเขียนในรายงานว่าที่ความสูงอื่นความเร็ว มม. จะต่างไปเท่าไร
- ปลาคร่อมขอบจะหักมุมตามรอยพับจริง (ส่วนใหญ่อยู่ใต้กรอบ 20 มม.) — ยอมรับได้

## 3. ความลึก: ปลาอยู่ในทะเล ไม่ได้ติดผิว — ดำลงแล้วปลาเลื่อนขึ้น เจอปลาชนิดใหม่

- ปลาแต่ละตัวมี **`sea_v`** = ตำแหน่งแนวตั้งในแผ่นทะเล (หน่วยเดียวกับ atlas v ของพื้นหลัง) แทนความสูงบนผิว
- ความสูงที่แสดงบนผิว ใช้**สูตรเดียวกับพื้นหลัง**กลับด้าน: `h = (center(depth) − sea_v) / vertical_scale × surface_vertical_scale_mm`
- ผล: ดำลึกขึ้น → `center(depth)` เพิ่ม → **ปลาและพื้นหลังเลื่อนขึ้นพร้อมกัน** · ปลาที่ลึกกว่าโผล่มาจากด้านล่าง · ปลาตื้นเลื่อนพ้นด้านบนหายไป
- ทิศของปุ่มลูกศรคงเดิม ห้ามสลับ
- ปลาทุกตัวต้องสแกนได้: มีความลึกสักค่าที่ทำให้ปลาอยู่ที่ `aim_height_mm` · และอยู่ในช่วงหมุนราว 270° · รายงานความลึก + มุมหันที่สแกนได้ของทุกตัว

## 4. เทสตัวเลข (Python + Node ผ่าน vectors ชุดเดียว)

1. เป้าเล็ง: ทุกมุมหันที่เป้าอยู่บนหน้าบน จุดเป้าอยู่บนเส้นทแยงแนวนอนของหน้านั้น (≤ 1 px) · ที่มุมหัน 0°/120°/240° อยู่กลางจอ (≤ 1 px) · ข้ามหน้าที่มุมข้าง
2. สัดส่วนปลา: ใช้สไปรต์ทดสอบรูปวงกลม วัดกว้าง:สูงบนจอ ที่กลางหน้า และใกล้ขอบช่องจอ บนหน้าบนและหน้าล่าง → อยู่ใน 1.00 ± 0.05 · ขนาด มม. ตรงค่าตั้ง ± 5%
3. ความลึก: เปลี่ยนความลึกจาก d1 เป็น d2 → ปลาทุกตัวเลื่อน `Δh` เท่ากับพื้นหลังที่จุดเดียวกัน (≤ 0.1 มม.)
4. hit test = สีพิกเซล (ของเดิมต้องยังผ่าน) · 12 ขอบยังต่อเนื่อง (ของเดิม)
