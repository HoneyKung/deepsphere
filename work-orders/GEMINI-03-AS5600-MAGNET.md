## ฮาร์ดแวร์ (ผู้ใช้ยืนยัน)
AS5600: VCC→**3V3** (ห้าม 5V) · GND→GND · SDA→**GPIO1** · SCL→**GPIO2** · DIR→**GND** · OUT/GPO ไม่ต่อ
**บอร์ด ESP32 หมุนไปพร้อมจอ** (อยู่บนถาดหมุนใต้ลูกบาศก์ กันสายจอบิด) · สายที่บิดตอนหมุนมีแค่ USB เส้นเดียว
**AS5600 อยู่บนถาดหมุนกับบอร์ด** คว่ำชิปลง ตรงกลางแกนหมุน · **แม่เหล็กอยู่บนเสากลางฐานที่นิ่ง** เม็ดแบน diametric ติด**นอน** หงายหน้าแบนขึ้นหาชิป ห่าง 1–2 มม.
ลูกบาศก์ตั้งบนมุม หมุนด้วยมือรอบแกนตั้ง ได้ราว 270° (ไม่มี slip ring) · ทิศมุมที่อ่านได้จะกลับด้านเทียบกับแบบชิปอยู่ฐาน → ตั้งด้วย `kYawReverse` จากผลเทสจริง ไม่เดา
ผู้ใช้ยังไม่บัดกรีขาโมดูล (6 รู)

## ช่วงที่ 1 — ทำได้ทันที (ไม่แตะ `firmware/`, ไม่ใช้บอร์ด)

1. **ตอบผู้ใช้ก่อนบัดกรี (ด่วน):** อ่าน datasheet ams AS5600 แล้วตอบพร้อมอ้างหน้า/หัวข้อ
   - ใช้ไฟ 3.3V ต้องเชื่อม VDD5V กับ VDD3V3 ไหม · ขอรูปโมดูลสองด้านจากผู้ใช้ แล้วบอกว่าต้องบัดกรีจุดไหนเพิ่มหรือไม่
   - มี pull-up SDA/SCL บนโมดูลไหม ไปต่อไฟเส้นไหน
   - DIR/OUT/GPO ต่อถูกตามข้างบนไหม
   - ที่อยู่ I2C และ register: RAW ANGLE, STATUS (MD/ML/MH), AGC, MAGNITUDE — ค่าจาก datasheet ไม่ใช่ความจำ
   - วิธีเช็คว่าแม่เหล็กเป็น diametric (เช่น หมุนแม่เหล็กนอนใกล้เข็มทิศ/แอปเข็มทิศ แล้วเข็มหมุนตาม)
   → เขียนลง `output/luna-10-status.md` หัวข้อ "ก่อนบัดกรี" และสรุปให้ผู้ใช้สั้น ๆ
2. **คณิตศาสตร์ล้วน** `tools/as5600_math.py` + เวอร์ชัน C++ ที่จะใช้ในเฟิร์มแวร์ (วางไว้ใน `firmware/src/sensors/` **ได้หลังช่วงที่ 2 เริ่ม** — ระหว่างนี้เขียนไว้ใน `output/as5600/draft/` ก่อน)
   - raw 12 บิต → องศา · deadband เล็ก ๆ · **offset ที่ย้ายจุดวนรอบ 359→0 ไปอยู่ในช่วงที่หมุนไม่ถึง** (ช่วงว่าง ~90°) จากค่า min/max ที่ calibrate
   - เทส Python + vectors JSON ที่ native C++ จะใช้ชุดเดียวกัน
3. **เครื่องมือให้ผู้ใช้รันเอง** `tools/as5600_watch.py`
   - ใช้ `SerialWorker` จาก `laptop/core.py` (DTR=1 RTS=0) · ไม่เพิ่ม dependency
   - แสดงสด: มุม, สถานะแม่เหล็ก, AGC, อัตราอ่าน · เก็บ CSV ลง `output/as5600/`
   - คำสั่งย่อย: `cal-start`, `cal-stop`, `zero`, `summary` (jitter ตอนนิ่ง p-p/SD, ก้าวกระโดดใหญ่สุด, ช่วงมุม, AGC ต่ำสุด–สูงสุด, ML/MH ที่เคยขึ้น, i2c_errors)
   - มีโหมด `--replay file.csv` เทสได้โดยไม่มีบอร์ด

## ช่วงที่ 2 — หลังผู้ใช้บอก "GEMINI-01 แฟลชเสร็จแล้ว"

ทำตาม LUNA-10 ข้อ 4 ส่วนเฟิร์มแวร์:
- `firmware/src/sensors/as5600.{h,cpp}` ใช้ `Wire` ของ framework · อ่าน ≥ 50 Hz ไม่ทำให้การวาดจอช้า · I2C มี timeout · นับอ่านพลาด
- ทำงานร่วมกับ **sweep mode ที่มีอยู่** (จอยังวนสีตามเดิม) · เพิ่มข้อความ `YAW 123.4 MAG OK` บรรทัดเดียวในแถบดำ ห้ามเปลี่ยนลำดับวาด/ความเร็ว SPI/คำสั่งเปิดจอ
- telemetry ผ่าน `sendLine` เส้นเดิมเท่านั้น (ห้ามเขียน Serial สองที่สลับกันกลางบรรทัด)
- คำสั่ง serial: `as5600_cal_start`, `as5600_cal_stop`, `as5600_zero` · เก็บค่าลง NVS ของ ESP32 (`Preferences`)
- แม่เหล็ก/เซนเซอร์หาย → `ok:false` พร้อมเหตุผล คงค่าล่าสุด ห้ามแต่งมุม
- **ยังไม่เอามุมไปขับการวาดทะเล**
- รันเทสทั้งหมด + native test + build `esp32-s3-zero` → **รอผู้ใช้อนุญาตก่อนแฟลช**

## ช่วงที่ 3 — ผู้ใช้เทสเอง (Gemini เตรียมเช็คลิสต์ ไม่ต้องคุม)

เขียน `output/as5600/user-checklist.md` ภาษาง่าย จากตาราง LUNA-10 ข้อ 5: ไม่มีแม่เหล็กในหลุมฐานนิ่ง → ใส่แม่เหล็กนอนหงายหน้าแบนขึ้นในหลุมใต้ชิป แล้ววางชุดให้นิ่ง 60 วิ → หมุนถาดช้า ๆ สุดทางไปกลับ 3 รอบ → ตรวจ AGC ตลอดช่วง → calibrate ช่วงหมุน → หมุนตามเข็มดูทิศ → สะบัดเร็ว → ถอดไฟเสียบใหม่ 3 ตำแหน่ง
แต่ละขั้นบอกว่าต้องรันคำสั่งอะไร และค่าแบบไหนคือผ่าน · **แนะนำให้ยังไม่ติดกาวแม่เหล็กจนกว่าจะผ่านขั้นวางนิ่งและหมุนช้า**
