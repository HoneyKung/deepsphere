## สัญญาระหว่างสองฝั่ง (ตกลงไว้ก่อน จะได้ทำพร้อมกันได้)

**บอร์ดส่งทาง serial บรรทัดละ 1 JSON อัตราราว 20–30 ครั้ง/วินาที:**
```json
{"v":1,"type":"yaw","deg":123.4,"raw":1402,"ok":true,"magnet":"ok"}
```
- `deg` 0–359.9 หลังใส่ offset/ทิศแล้ว · `ok` false เมื่ออ่านเซนเซอร์ไม่ได้ · `magnet` = `ok` / `weak` / `strong` / `missing`
- บรรทัดอื่นที่บอร์ดส่งอยู่แล้วคงไว้ ห้ามทำของเดิมพัง

**สะพาน (bridge) บนโน้ตบุ๊กเปิด HTTP ที่ 127.0.0.1:8765:**
- `GET /twin/...` เสิร์ฟไฟล์เว็บเหมือน `python -m http.server` เดิม
- `GET /yaw` ตอบ `{"deg":123.4,"ok":true,"magnet":"ok","age_ms":12}` · ถ้าไม่มีบอร์ด ตอบ `{"ok":false,"reason":"no board"}`

## ฝั่งบอร์ด — Gemini ตัวแม่เหล็ก

1. อ่าน AS5600 ผ่าน `Wire` ที่ **SDA=GPIO1, SCL=GPIO2** (ที่อยู่ 0x36, RAW ANGLE 0x0C/0x0D, STATUS 0x0B) ตามงานช่วงที่ 1 ที่ทำไว้แล้ว
2. อ่านที่ ≥ 50 Hz จากงานแยก ไม่ให้การวาดจอมาหน่วง แล้วส่งบรรทัด `yaw` ตามสัญญาข้างบนที่ 20–30 Hz
3. ใช้ deadband เล็ก ๆ กันค่าสั่น · เซนเซอร์หายหรือแม่เหล็กหาย ให้ `ok:false` **ห้ามแต่งมุม**
4. ตั้งศูนย์: คำสั่ง `as5600_zero` (มุมปัจจุบัน = 0) เก็บลง NVS · ทิศกลับด้วย `kYawReverse` จากผลหมุนจริง ห้ามเดา
5. **ถ้าจอทำให้ลูปช้าจนส่ง yaw ไม่ทัน** ให้เพิ่มค่าคงที่ปิดการวาดจอชั่วคราวได้ (ค่าเริ่มต้นคือเปิดไว้เหมือนเดิม)
6. เทส + build + แฟลช COM6 · **หลังแฟลชห้ามเปิดโปรแกรมถือพอร์ตค้างไว้** ปล่อยพอร์ตให้ bridge ใช้

## ฝั่งเว็บ — Gemini ตัวเว็บ

1. `laptop/twin_bridge.py` ใช้ **standard library เท่านั้น** + `SerialWorker` จาก `laptop/core.py` (DTR=1 RTS=0 เจ้าของพอร์ตคนเดียว)
   - เสิร์ฟไฟล์ในโปรเจกต์เหมือนเดิม + endpoint `/yaw` ตามสัญญา
   - `--port COMx` และ `--simulate` (ไม่มีบอร์ด ให้ `/yaw` ส่งมุมเดินช้า ๆ เพื่อเทสเว็บ)
   - บอร์ดหลุด → `/yaw` ตอบ `ok:false` ไม่ค้าง ไม่พัง
2. `twin/`: เปิดด้วย `?live=1` แล้ว **poll `/yaw` ทุก 50 ms**
   - ได้ `ok:true` → ตั้งมุมกล่องจาก `deg` และ **ปิดลูกศรซ้าย/ขวากับการลากเมาส์หมุนกล่อง** (กันสองแหล่งชนกัน) · ค่อย ๆ ไล่ตามมุม (interpolate) ให้ลื่น
   - ได้ `ok:false` หรือ fetch ล้มเหลว → ป้ายหัวเว็บเป็น `BOARD DISCONNECTED` และกลับไปใช้ลูกศรได้
   - ป้ายสถานะ: `LIVE — MAGNET yaw 123.4°` / `SIMULATED — NO BOARD` / `BOARD DISCONNECTED` · ป้าย SIMULATED เดิมห้ามหาย
3. ความลึกด้วยลูกศรขึ้น/ลง และ numpad 1/2/3 ยังทำงานเหมือนเดิม
4. **บั๊กเป้าเล็งหลุดขอบจอที่ Claude แจ้งไว้ ยังต้องแก้** ถ้าเวลาไม่พอ ให้แก้ข้อนี้ก่อนงานเดโม

## เกณฑ์ผ่าน (ผู้ใช้ดูเอง)
1. รัน bridge หนึ่งคำสั่ง เปิดเว็บ `http://127.0.0.1:8765/twin/index.html?live=1`
2. **หมุนแม่เหล็กด้วยมือ → กล่องบนเว็บหมุนตามทิศเดียวกัน** หยุดแล้วนิ่ง ไม่สั่น
3. ดึงแม่เหล็กออก → เว็บขึ้นว่าไม่มีสัญญาณ แล้วใส่กลับ → กลับมาหมุนตามได้เอง
4. ถอด USB → `BOARD DISCONNECTED` · เสียบกลับ → กลับมาเองโดยไม่ต้องรีโหลดหน้า

## ห้าม
- ถือพอร์ต COM ด้วยโปรแกรมอื่นตอน bridge ทำงาน (เปิดได้ทีละโปรแกรม)
- เพิ่มไลบรารีใหม่ · แก้ไฟล์ใน `work-orders/` · แตะโค้ดวาดจอ ST7789 นอกจากข้อ 5 ฝั่งบอร์ด
- แต่งมุมเมื่อเซนเซอร์ไม่มีข้อมูล
