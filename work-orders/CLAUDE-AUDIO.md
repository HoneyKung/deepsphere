# ใบสั่งงาน: Claude Code — หาและเตรียมเสียงใหม่

สถานะ: พร้อมให้ผู้ใช้ส่งต่อ ยังไม่ได้ค้นหา ดาวน์โหลด หรือมอบหมายงานเสียงจาก task นี้

## คำสั่งงานพร้อมใช้

หาและดาวน์โหลดเสียงใหม่สำหรับ Deep Sphere ต้นแบบเล็ก จอคอมเป็นแผงควบคุมเรือดำน้ำและเล่นเสียง ขณะ ESP32 ส่งเหตุการณ์ Scan/Collect/Analyze ผ่าน USB ทำงานเฉพาะใน `C:/Users/Acer/Downloads/oceanX/prototype-v1/assets/audio/` และเขียนบันทึกส่งมอบ `output/audio-status.md` อ่าน `docs/audio-protocol.md` เพื่อใช้ชื่อ cue และรูปแบบ catalog ตรงกัน

ห้ามอ่านหรือใช้เสียงจากเดโมเก่า ผู้ใช้ระบุว่าเสียงชุดเก่าไม่ดี ต้องเลือกใหม่ ไม่แก้ firmware หรือโปรแกรม receiver ที่ Luna รับผิดชอบ ห้ามใส่อีโมจิในไฟล์โค้ด

## โทนที่ต้องการ

บรรยากาศสำรวจทะเลและเครื่องมือเรือดำน้ำ เสียงโปร่งพอให้ฟังปุ่มชัด ระดับลึกค่อย ๆ มืดและหนักขึ้น ไม่มีเพลงร้อง เสียงพูด stock ที่รบกวน หรือเสียงดังแหลมฉับพลัน ใช้ sound design ได้ ไม่อ้างว่าเป็นเสียง hydrophone หรือเสียงสัตว์จริงหากแหล่งต้นฉบับไม่ได้ยืนยัน

## รายการเสียง

| cue_id | สิ่งที่หา | ลักษณะส่งมอบ |
|---|---|---|
| ambient_surface | น้ำ/บรรยากาศใต้น้ำค่อนข้างสว่าง | loop 20–60 วินาที |
| ambient_mid | บรรยากาศใต้น้ำทึบขึ้น | loop 20–60 วินาที |
| ambient_deep | เสียงพื้นหลังลึกและสงบ | loop 20–60 วินาที |
| scan_hit | ยืนยันตรวจพบ สำเร็จ | one-shot ประมาณ 0.2–1 วินาที |
| scan_miss | ไม่พบเป้าหมาย โทนเบากว่า hit | one-shot ประมาณ 0.2–1 วินาที |
| collect_success | จับภาพ/บันทึกตัวอย่างสำเร็จ โทนเครื่องมือ | one-shot ประมาณ 0.2–1 วินาที |
| analyze_open | เปิดข้อมูลวิเคราะห์ โทนอ่านผลเครื่องมือ | one-shot ประมาณ 0.3–1.5 วินาที |
| action_error | ยังทำรายการไม่ได้ เบาและไม่รบกวน | one-shot ประมาณ 0.2–0.8 วินาที |

ถ้าใช้แหล่ง ambience เดียวแล้วปรับเป็นสามระดับได้ดี สามารถทำได้โดยระบุ processing จริง ไม่ต้องหาแปดแหล่งเพียงเพื่อให้จำนวนแหล่งครบ เสียง Scan อาจมีลักษณะ ping ได้ แต่ไม่มีปุ่ม Sonar แยกและไม่มีปุ่มกลับผิวน้ำ

## วิธีเลือกและสิทธิ์

- ใช้แหล่งที่ดาวน์โหลดได้อย่างถูกต้องและมีเงื่อนไขใช้งานชัด เลือก CC0 หรือสิทธิ์ที่รองรับการเดโม/นำเสนอและวิดีโอของโครงการ
- บันทึก source URL ของเสียงแต่ละชิ้น ผู้สร้าง ชื่อ license ลิงก์ license และข้อความ attribution ที่ต้องใช้
- อย่าใช้คลิปเสียงจาก YouTube หรือหน้า preview ที่ไม่มีสิทธิ์ดาวน์โหลดชัดเจน
- ไม่ซื้อเสียง สมัครสมาชิก หรือใช้บัญชีที่ต้องให้ผู้ใช้จ่ายเงินโดยไม่ได้รับคำสั่ง
- ฟังและคัดเองก่อนส่ง ไม่ส่งเพียงลิงก์รายชื่อ ไม่เลือกจากชื่อไฟล์อย่างเดียว

## การเตรียมไฟล์

- ส่ง WAV PCM 16-bit 44.1 kHz stereo; ตัด silence ที่ไม่ตั้งใจและทำขอบ loop ให้ไม่สะดุด
- ฟังผสม ambience กับ one-shot ให้เสียงปุ่มชัดโดยไม่ดังโดด ระบุ gain_db ใน catalog สำหรับตั้งต้น
- ระบุการ trim, fade, EQ, resample หรือการดัดแปลงอื่นตามจริง ไม่อ้างว่าฟังหรือประมวลผลแล้วถ้ายังไม่ได้ทำ
- ส่งไฟล์เสียงที่ใช้จริงไว้ระดับบนของ `assets/audio/` เก็บต้นฉบับแยก `originals/` ได้เพื่อย้อนตรวจที่มา

## สิ่งส่งมอบ

1. ไฟล์ WAV ตามชื่อ cue ทั้งแปด หรือระบุรายการที่ยังหาไม่ได้อย่างชัดเจน
2. `assets/audio/catalog.json` ตาม schema ใน `docs/audio-protocol.md`
3. `assets/audio/ATTRIBUTION.md` ที่นำไปใส่เครดิตงานได้
4. `output/audio-status.md` สรุปคุณภาพ เสียงที่เลือก แหล่ง/สิทธิ์ และข้อที่ยังค้าง

เกณฑ์ผ่าน: เปิดเล่นทุกไฟล์ได้ loop ไม่สะดุดอย่างเห็นชัด ชื่อ cue ตรง protocol มีที่มาครบ และทดสอบฟังจากโน้ตบุ๊กจริงได้ หากมีข้อสงสัยด้าน receiver ให้ส่งข้อสังเกตแก่ Astra/Luna ไม่เปลี่ยน event contract เอง
