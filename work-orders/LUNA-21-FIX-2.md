# ใบ 21 รอบแก้ 2 — ผู้ตรวจเดิมตัดสิน FIX FIRST (2026-10-28)

ขอบเขตไฟล์และกฎใช้ตามใบ LUNA-21 เดิม: ห้ามแตะไฟล์ wav, ห้ามแตะส่วน LUNA-17/20, ห้าม commit/push · เขียนภาษาไทยด้วย UTF-8 ห้ามใช้ PowerShell Set-Content/Out-File
ส่วนที่ผ่านแล้วจากรอบ 1: found ที่ t=0 แล้ว pass ที่ t=1 ได้ 1 บท, pass ที่ไม่มี found ได้ 1 บท, ขาขึ้นเงียบ, ไม่ชนกับ vo_max_depth_v2

## ข้อ 1 — `VOICE_POLICY` เสีย (`twin.js:813`) (หัวงานตรวจแล้ว เป็นจริง)
- ที่ควรเป็นกฎเว้นระยะของ `vo_gate_hint/found/pass` ตอนนี้กลายเป็นอ็อบเจกต์ `{th, en}` แบบ `VOICE_LINES` น่าจะเกิดจากการแทนที่ข้อความผิดจุด
- แก้: คืนกฎของทั้ง 3 id ตามที่ร่างบทเสนอ (และให้สอดคล้องกับ cooldown ต่อช่องที่ `:1572`, `:1636`) แล้วตรวจว่า `VOICE_LINES` ยังถูกต้องครบ

## ข้อ 2 — pass ยังพูดทับบทอื่นได้ (`twin.js:1591-1595`, `:924`)
- โค้ดเช็กแค่ว่า `vo_gate_found` กำลังพูดอยู่หรือเปล่า แต่ `speakLine` ไม่เคยหยุดเสียงพากย์ที่กำลังเล่นอยู่ และ pass ข้ามกฎ 4 วินาทีไปแล้ว
- กรณีจริง: ชนพื้น → hint พูด (5.96 วิ) → ผู้เล่นหมุนภายใน 4 วิ found เลยโดนกฎ 4 วิตัด → ดำผ่านที่ ~3 วิ → pass พูดทับ hint · เกิดแบบเดียวกันกับบท scan/collect
- แก้: **ห้ามมีเสียงพากย์สองบทเล่นพร้อมกันเด็ดขาด** · ถ้ามีบทพูดอยู่ ให้ pass เข้าคิวรอจนบทนั้นจบ (ถ้าเหมาะกว่า จะหยุดบทเดิมแบบค่อย ๆ เบาลงก็ได้ แต่ห้ามตัดกลางประโยคทันที) แล้วเขียนเหตุผลที่เลือก · ถ้าเข้าคิวรอนานเกินไป เช่นผู้เล่นลงไปถึงชั้นถัดไปแล้ว ให้ทิ้งบท pass แล้วให้บทโซนทำงานตามปกติแทน เพื่อให้ยังได้ 1 บทเสมอ

## ข้อ 3 — เทสต้องใช้โค้ดจริง
- `tests/test_luna21_voice_behavior.cjs:41` สร้าง `VOICE_POLICY` ขึ้นมาเองในเทส ไม่ได้โหลดของจริง จึงจับข้อ 1 ไม่ได้
- stub `speakLine` (`:53-58`) ไม่มีเวลาจบบทและไม่ตรวจการพูดทับ จึงจับข้อ 2 ไม่ได้
- ส่วน "legacy" (`:96-112`) เป็นโค้ดที่เขียนเลียนแบบขึ้นมาใหม่ ไม่ใช่โค้ดเดิมจริง
- แก้: ดึง `VOICE_POLICY`/`VOICE_ALWAYS`/`voiceAllowed`/`speakLine` และฟังก์ชัน gate จาก `twin.js` ของจริงมารันใน node · ทำ stub เสียงให้มีความยาวตามไฟล์จริง (อ่านความยาวจาก wav หรือใส่ตัวเลขจาก `tools/voice/render-voice-v2.json`) แล้วตรวจว่าไม่มีช่วงเวลาไหนที่เสียงพากย์สองบทเล่นพร้อมกัน
- กรณีที่ต้องทดสอบ:
  - (ก) hint แล้วผ่านช่องที่ 3 วิ
  - (ข) บท scan แล้วผ่านช่อง
  - (ค) found แล้วผ่านช่องที่ 1 วิ
  - (ง) ผ่านช่องโดยไม่มีบทอื่นพูดอยู่
  - (จ) ขาขึ้น
  - ทุกกรณีต้องได้ 1 บทพอดีต่อการผ่านช่อง และไม่มีบทพูดทับกัน
- ลองให้เทสล้มกับโค้ดรอบ 1 (ใช้ git stash หรือสำเนาไฟล์) แล้วเขียนผลลงรายงาน
