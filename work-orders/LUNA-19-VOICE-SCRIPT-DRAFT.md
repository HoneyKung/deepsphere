คุณคือ Luna ลงมือทำงานโดยตรง ห้ามเรียก codex exec ซ้อน
ไฟล์ที่เขียนได้: `docs/voice-script-v2.md` (ใหม่), `output/luna-19-status.md`
ห้ามแตะ: ทุกไฟล์ใน `twin/`, `assets/` (รวม `sound-manifest.json` และไฟล์เสียง), `firmware/`, `laptop/`, `config/` — ใบนี้**อ่านอย่างเดียว ยกเว้นสองไฟล์ด้านบน**

- `twin/renderer.js` — `ART` (รายชื่อสัตว์ที่วาดจริง), ชั้นความลึกแต่ละชั้น

- ถ้าหาข้อความบทเดิมเจอในไฟล์ใดก็ได้ใต้ `prototype-v1/` ให้ใช้ข้อความนั้น ถ้าหาไม่เจอให้เขียนว่า "ไม่พบข้อความเดิม" ห้ามเดา
กฎ: UTF-8, grep เครื่องหมายคำถามสี่ตัวติดกันต้องได้ 0, คำอธิบายเขียนเป็นภาษาไทย บทพูดเขียนเป็นภาษาอังกฤษ (เสียงพากย์เป็นภาษาอังกฤษ: en-US-MichelleNeural ผ่าน edge-tts)

## เหตุและหลักฐาน
- เจ้าของบอก 2026-10-27: เสียงโอเคแล้ว เหลือแค่ทำบทพากย์ให้ตรงกับเว็บ
- มีไฟล์เสียงพากย์ 22 ไฟล์ใน `assets/audio/voice/` ซึ่งทำไว้ตั้งแต่ 2026-10-02 ก่อนเว็บจะมี 3 ชั้นที่มีช่องลง, การ์ดสปีชีส์ และสัตว์แยกชั้น (เพิ่ม 2026-10-09)
- กฎเจ้าของ: ห้ามลบหรือทับไฟล์เสียงเดิม ถ้าต้องอัดใหม่ให้ใช้ชื่อไฟล์รุ่นใหม่ — ใบนี้ยังไม่อัดเสียง
- โทนเสียงที่เจ้าของเลือก: ผู้หญิง นุ่ม หวาน แนว ASMR บรรยากาศ "ลึกลับ น่าค้นหา ไม่น่ากลัว" แบบเกม Sky

## ต้องทำ
1. ตารางบทเดิม: ทุก `vo_*` ที่มีไฟล์ → id / ข้อความเดิม (ถ้าพบ) / เล่นตอนไหน (ไฟล์:บรรทัด) / กฎการเล่นซ้ำจาก `VOICE_POLICY`
2. ตารางช่องโหว่: เหตุการณ์ในเว็บตอนนี้ที่ควรมีเสียงพากย์แต่ยังไม่มี (เช่น เจอช่องลง, ผ่านชั้น, ถึงพื้นชั้นล่างสุด, เปิดการ์ด, สัตว์ใน `SPECIES` ที่ไม่มี `vo_name_*`) และบทเดิมที่ไม่ตรงกับเว็บแล้ว (เช่น ชื่อโซนที่ไม่ตรงกับ 3 ชั้น) — ทุกข้อต้องอ้างไฟล์:บรรทัด
3. ร่างบทใหม่: แต่ละแถวมี id / สถานะ (คงเดิม · แก้ · ใหม่) / บทภาษาอังกฤษ (ไม่เกิน ~12 คำ พูดได้ใน 4 วินาที) / คำแปลไทย / เหตุผลสั้น ๆ · id ใหม่หรือรุ่นแก้ให้ใช้ชื่อ `vo_<เดิม>_v2` ห้ามใช้ชื่อซ้ำกับไฟล์เดิม
4. ข้อเสนอการผูกโค้ด (เขียนอย่างเดียว ห้ามแก้โค้ด): จุดที่ต้องเรียก `speakLine` เพิ่ม และกฎเล่นซ้ำที่แนะนำสำหรับ id ใหม่ เพื่อไม่ให้พูดถี่จนรำคาญ
5. คำถามถึงเจ้าของไม่เกิน 3 ข้อ แต่ละข้อมีคำแนะนำ (เช่น ให้พูดชื่อสัตว์ทุกตัวไหม)

## ห้ามทำ
- ห้ามแก้โค้ดหรือไฟล์เสียง ห้ามสร้างไฟล์เสียง ห้ามดาวน์โหลด
- ห้ามแต่งข้อเท็จจริงทางวิทยาศาสตร์ที่ไม่มีอยู่ใน `SPECIES` หรือการ์ด
- ห้ามทำให้ภาษา/encoding เสีย
